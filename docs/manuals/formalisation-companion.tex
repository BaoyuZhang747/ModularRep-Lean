{\Huge Formalisation Report\par}
\vspace{12mm}
{\Large On the inductive blockwise Alperin weight condition\par
for type B and type C\par}
\vfill
\begin{minipage}{0.85\textwidth}
This report explains arguments concerning the inductive blockwise
Alperin weight condition for simple groups of Type B, simple groups of
Type C and sporadic simple groups, together with their consequence for
finite groups. The results checked in Lean depend on the stated assumptions about
the groups, characters, blocks and computational data. The exposition
identifies the Mathlib foundations, general ModularRep results and
deductions for these families.
\end{minipage}

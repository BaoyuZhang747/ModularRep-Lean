Purpose

Combines exhaustive ordinary local rows into all weight classes and their fixed points.

Mathematical statement and assumptions

A bijective radical-class catalogue and bijective local defect-zero row catalogues give global and fixed-point equivalences and sum formulas, allowing empty local catalogues.

Argument or construction

Compose each local row equivalence with the representative weight-fibre equivalence and sum over radical classes. For fixed points, choose an inner correction at each fixed radical class and restrict to ordinary rows fixed by the corrected local action. Sigma cardinality gives both total and fixed sums.

External assumptions and dependencies

Actual exhaustive radical and ordinary character catalogues; finite row types for the cardinality conclusions.

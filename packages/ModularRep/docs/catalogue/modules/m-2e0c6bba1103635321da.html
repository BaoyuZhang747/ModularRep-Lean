ModularRep.ComputationTranscriptPure

ModularRep/ComputationTranscriptPure.lean

computation-bindingauxiliary

Purpose

Unlike ComputationTranscriptElab, the functions in this module are ordinary Lean definitions.

Mathematical statement and assumptions

Pure line and list parsers return the specified projections of literal transcript strings and satisfy checked acceptance/rejection examples under their exact token convention.

Argument or construction

Define pure parsers for transcript lines, fields, integer lists and row projections. Kernel evaluation proves examples of acceptance and rejection on strings; the first-key behavior is distinct from duplicate rejection in the elaboration layer.

External assumptions and dependencies

Literal strings supplied to the pure Lean parsers and their stated token convention. Example evaluations prove parser behavior, without any theorem about external file IO or the producing computation.

Purpose

Makes the common Q=1 extension construction universal in the retained global model.

Mathematical statement and assumptions

Every factor-one irreducible model affording the base character has a common extension pair at compatible roots, or at a root obtained from a seed.

Argument or construction

Apply the common-extension theorem separately to each model without changing it. Package the statement universally and specialize it to an arbitrary finite-dimensional representation via FDRep.of.

External assumptions and dependencies

The actual base square and Q=1 local character equation, affording/factor-one data, and compatible roots or an ambient seed.

ModularRep.PaperProofs.TypeBRankThreeJordanPacketCarriers

ModularRep/PaperProofs/TypeBRankThreeJordanPacketCarriers.lean

carrier-constructionauxiliary

Purpose

Defines complete modular packets by a central idempotent on literal Brauer characters.

Mathematical statement and assumptions

Each character's supporting primitive block is computed from the specified decomposition.

Argument or construction

Block orthogonality identifies packet membership with nonzero support and reconstructs the idempotent as its supported block sum. Idempotent invariance gives the packet action and its value formula.

External assumptions and dependencies

Specified primitive decomposition, canonical character injectivity and explicit centrality/idempotence.

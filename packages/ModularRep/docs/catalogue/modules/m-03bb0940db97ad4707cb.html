Purpose

Derives centrelessness from the complete class table.

Mathematical statement and assumptions

A complete 108-class representative cover with the stated centralizer orders and group order has trivial centre.

Argument or construction

A central element has full centralizer order, which the literal table permits only at class zero. The cover of the identity identifies that class representative with one, so every central element is one.

External assumptions and dependencies

A complete 108-class conjugacy cover, actual centralizer cardinalities equal to the literal table and the specified group order. No character, block or root data are needed to derive the centre.

ModularRep.PrimeRegularEvaluationMatrix

ModularRep/PrimeRegularEvaluationMatrix.lean

theorem-developmentcurrent

Purpose

This file combines the abstract evaluation matrix theorem with the fact that modular traces depend only on the prime regular part of a group element.

Mathematical statement and assumptions

A linearly independent family of modular trace characters admits a nonsingular evaluation matrix whose evaluation elements are all prime regular.

Argument or construction

Replace each element in a nonsingular trace evaluation matrix by its prime regular part, which has the same modular trace. This gives an equally nonsingular evaluation matrix on prime regular elements.

External assumptions and dependencies

A finite group, characteristic-p representations with p prime and linear independence of their trace functions; uses the prime regular-part trace equality.

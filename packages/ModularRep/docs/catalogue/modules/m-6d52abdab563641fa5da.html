Purpose

Computes the base and centralizer in a restricted automorphism ambient.

Mathematical statement and assumptions

The intermediate subgroup contains the actual inner base and is later taken to be an upstairs stabilizer image.

Argument or construction

Restriction gives the base equivalence and normalizer square. Since its base centralizer is trivial, the restricted ambient has trivial centre and the stated centre-quotient identification.

External assumptions and dependencies

The actual ambient construction, centreless base and proved subgroup containment.

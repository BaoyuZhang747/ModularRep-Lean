Purpose

Proves the global and local base characters invariant in the constructed original ambient.

Mathematical statement and assumptions

The trivial-sector original ambient fixes its transported global base character; the same matched equivariant correspondence fixes the transported local base character.

Argument or construction

Global fixedness is built into the actual Brauer automorphism stabilizer and transports through its base equivalence. Local fixedness follows from the original raw match and covariance, using the derived own-quotient automorphism square. Perfectness and the central kernel are derived from the cover and sector.

External assumptions and dependencies

Universal cover and trivial-sector equation, canonical local reduction/block compatibility and the same equivariant match.

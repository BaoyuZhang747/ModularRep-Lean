Purpose

Stores the full trivial-sector polynomial rows and their column routing and outer permutation.

Mathematical statement and assumptions

The literal payload consists of 108 rows on 91 columns, a routing to 41 representative columns and a specified full-column permutation.

Argument or construction

The file defines the exported finite arrays and combines the raw row function. Reconstruction, duplicate-column and involution assertions are proved in the dedicated check modules, and actual character interpretation is supplied separately.

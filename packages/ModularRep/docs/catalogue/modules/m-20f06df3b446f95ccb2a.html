Purpose

Constructs the local normalizer component of an original-cover packet.

Mathematical statement and assumptions

The local group is the normalizer of the raw image radical; the local map has the natural global square and range equal to the base intersection.

Argument or construction

A stored normalizer-base equivalence defines the local map from the own-normalizer map. Surjectivity of the latter proves the range equation, with the trivial-central-sector specialization using the actual quotient embedding.

External assumptions and dependencies

An original ambient and own quotient/radical, together with an equivalence from its quotient normalizer to the base intersection. Its range theorem uses the same fixed-central-quotient normalizer source; the trivial-sector construction uses the actual full cover and global trivial-centre equation.

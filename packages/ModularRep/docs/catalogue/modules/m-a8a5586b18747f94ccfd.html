Purpose

Proves finiteness of the whole set of weights from finite central-sector counts.

Mathematical statement and assumptions

A trivial sector of size 41 and every other central sector of size 25 imply that the actual set of weights is finite.

Argument or construction

Each sector is finite because its natural cardinality is positive. The finite actual block catalogue indexes sector fibres, and the finite sigma of those fibres surjects onto all weights by choosing each weight's own block.

External assumptions and dependencies

The actual finite block catalogue and the stated sector counts; no finiteness of the entire central character type is required.

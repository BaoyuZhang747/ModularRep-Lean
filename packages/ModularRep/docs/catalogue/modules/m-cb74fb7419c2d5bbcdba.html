Purpose

Combines the centreless index-two family with Q=1 intermediate block laws.

Mathematical statement and assumptions

Centrelessness, actual outer order two, specified base catalogues, local availability and defect-zero blocks give the same family with AD3, block preservation, normalization and common-extension block data.

Argument or construction

The explicit index-two comparison supplies the model family. Block preservation normalizes the same map, and the stored common global extension is transported to its local group with all intermediate catalogue laws.

External assumptions and dependencies

Centrelessness, actual outer order two, the root and literal carrier adapter, canonical block compatibility/availability, defect-zero reduction and trivial-weight sources, a faithful-sector reference map with stabilizer equivariance and specified block preservation, and the singleton defect-zero ordinary-block source. Unselected catalogues for proper actual automorphism ambients and existence of roots on those same ambients remain explicit inputs.

Purpose

For a matched weight whose quotient radical is trivial, the ambient local normaliser is canonically the whole ambient group.

Mathematical statement and assumptions

For Q=1, one common extension can serve in both global and local positions after the canonical whole-normalizer and root identifications.

Argument or construction

For the trivial radical, identify the local normalizer with the whole base group. Transport one common extension into both global and local positions using the specified root and quotient identifications.

External assumptions and dependencies

One common Q=1 representation/character extension, its ambient root agreement and the local quotient/transport data of the same matched pair.

Purpose

Derives actual trivial-sector weight totals 41 and 31 from corrected Table 8.

Mathematical statement and assumptions

An exhaustive 34-radical catalogue with actual local total/fixed bindings and a permutation to corrected Table 8 gives 41 sector weights and 31 fixed sector weights.

Argument or construction

Transport actual fixed local characters to corrected catalogue rows. All radical classes are fixed, so the fixed index set is Fin 34. Permuting the literal table preserves its sums; the original-sector weight and fixed-weight construction equivalences transfer these sums to the specified carriers.

External assumptions and dependencies

Actual exhaustive radical representatives, inner corrections, actual ordinary rows and action bindings, corrected-table permutation, canonical reductions and quotient compatibility.

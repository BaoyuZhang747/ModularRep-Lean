Purpose

This file identifies conjugation by the quotient pair stabiliser with the automorphism transport already contained in stabilisation of the selected character weight.

Mathematical statement and assumptions

For the selected own local Brauer reduction, actual pair-stabilizer covariance proves invariance on its local base; the cyclic extension principle then yields an extension of that same character.

Argument or construction

Prove fixedness of the selected local Brauer character on the actual local base using the raw weight action and reduction source. The previously proved cyclic quotient then allows the cyclic extension principle to construct its extension.

External assumptions and dependencies

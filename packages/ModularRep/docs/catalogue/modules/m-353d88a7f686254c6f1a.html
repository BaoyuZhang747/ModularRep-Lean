Purpose

This is a one-way external certificate for the individual rational-series integral basic sets in Feng--Li--Zhang (2022), Theorem 2.3, p. 537.

It is indexed by one rational-series family, one actual group, one modular system, and the literal primitive modular blocks. Its Brauer partition is the composite of the actual block assignment and the supplied Broue--Michel block index.

External assumptions and dependencies

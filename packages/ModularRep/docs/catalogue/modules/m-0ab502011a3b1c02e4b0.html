ModularRep.DecompositionBasicSetBridge

ModularRep/DecompositionBasicSetBridge.lean

transport-adaptercurrent

Purpose

Connect actual exact decomposition maps and injectively labelled integral basic sets to equivariant finite set equivalences.

Mathematical statement and assumptions

A restricted integral basic set with compatible injective simple labels and exact decomposition naturality gives an equivariant integral permutation-module isomorphism, and under the stated Conlon hypotheses an equivariant set equivalence.

Argument or construction

Injective simple-module labels identify the restricted decomposition map with an integral linear isomorphism. K-zero naturality reflects to coefficient equivariance, and the explicit Conlon/Burnside hypotheses produce a set equivalence.

External assumptions and dependencies

RestrictedIntegralBasicSet with injective actual simple-class labels, the stated label action and decomposition naturality. Conlon/Burnside sources and the hypoelementary actor are additional hypotheses of the set-equivalence endpoint.

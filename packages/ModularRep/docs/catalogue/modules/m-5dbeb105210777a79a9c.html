Purpose

This module isolates the formal block calculation that becomes available when a local normaliser is the whole intermediate group.

Mathematical statement and assumptions

Restricting the common Q=1 packet through each intermediate group gives the required block equalities by self-induction on the same actual catalogue.

Argument or construction

Restrict the common Q=1 extension through each intermediate subgroup. Coefficient-level self-induction on the same catalogue and the canonical identifications prove the intermediate block equality.

External assumptions and dependencies

The common Q=1 extension packet, compatible roots and canonical intermediate local/global identifications. The self-induction argument uses the same specified primitive catalogue on both sides.

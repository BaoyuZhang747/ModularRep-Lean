Purpose

Derives root compatibility across two quotient normalizers.

Mathematical statement and assumptions

The canonical normalizer roots upstairs and downstairs agree under the surjective local map when both come from the same ambient embedding.

Argument or construction

Each canonical normalizer convention restricts the original root table. The surjective-root construction therefore agrees with the downstairs convention, giving compatibility for every representation.

External assumptions and dependencies

Two canonical reductions attached to the original and quotient ambient root conventions, together with a surjective map between the actual normalizers. Root agreement is a conclusion, not a separate source law.

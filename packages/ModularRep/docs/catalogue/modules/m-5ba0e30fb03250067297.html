Purpose

Builds the local wreath-character formula indexed by coloured staircase cores.

Mathematical statement and assumptions

Each actual local defect-zero character receives a core, and the sum of core sizes equals the repeated subgroup multiplicity.

Argument or construction

Explicit tensor-permutation matrices define the Young-inertia character and finite induction defines the output. The scoped source supplies irreducibility, defect zero and exhaustive injective enumeration.

External assumptions and dependencies

An (6D), FM Proposition 5.4, actual colour-block permutation restrictions and symmetric-group staircase characters; a multicolour total need not be triangular.

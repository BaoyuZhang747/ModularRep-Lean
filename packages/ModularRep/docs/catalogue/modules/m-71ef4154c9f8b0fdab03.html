Purpose

Attaches all intermediate block laws to every actual common Q=1 extension pair.

Mathematical statement and assumptions

A base/top subgroup dichotomy, the base catalogue and an unselected top catalogue imply CommonPairIntermediateBlocks.

Argument or construction

At the base use the extension's restriction identity and transported base catalogue. At top use the chosen global extension itself and a transported ambient catalogue. Open an existing common-extension witness once and attach these laws to those exact two characters.

External assumptions and dependencies

The common extension equation, base/top interval and actual catalogues.

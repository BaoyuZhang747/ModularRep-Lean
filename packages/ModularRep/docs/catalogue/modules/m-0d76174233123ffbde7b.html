Purpose

This module contains the elementary group-theoretic map from a subgroup to its image in a quotient.

Mathematical statement and assumptions

The quotient map restricted to a subgroup containing its normal kernel corestricts to that subgroup's actual quotient image and has the stated ambient class formula.

Argument or construction

Restrict the quotient map to a subgroup containing the normal kernel and corestrict it to its image. The elementwise formula identifies it with the ambient quotient class.

External assumptions and dependencies

A normal subgroup Q of D and a subgroup N containing it, with the canonical quotient image.

Purpose

Records the full faithful ordinary restriction matrix and column expansion witnesses.

Mathematical statement and assumptions

The literal 74 by 91 matrix is related to 25 selected coordinates using seven conductor tags, column descriptors and polynomial quotient witnesses.

Argument or construction

The arrays store all raw rows and full-column residual quotients. Closed divisor and pivot checks establish the descriptor prerequisites; specified character-value identification is separate.

External assumptions and dependencies

The literal data and closed identities described in this entry. Actual group, ordinary-character, block or coefficient identification is a separate binding and is not proved by this data module.

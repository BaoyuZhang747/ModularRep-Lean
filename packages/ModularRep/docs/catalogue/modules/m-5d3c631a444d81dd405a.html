Purpose

Builds the rational product from original nonpermuted component fixed points.

Mathematical statement and assumptions

Each computed component cycle has length one and retains its original Frobenius coordinate.

Argument or construction

Singleton cycle and monomial coordinates are constructed from the original group product. The fixed-product equivalence then gives the rational product, with the return map identified with the original one-step action.

External assumptions and dependencies

Original geometric coordinates, component inclusions and Frobenius equations; no rational product is an input.

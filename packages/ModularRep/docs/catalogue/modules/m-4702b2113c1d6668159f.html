theorem-developmentcurrent

Purpose

For a finite group G, this file constructs the raw group algebra sum of a conjugacy class and proves that it is central.

Mathematical statement and assumptions

Coefficient restriction of a global conjugacy class sum equals its subgroup-intersection sum, giving the corresponding formula for induced central functions.

Argument or construction

Define group conjugacy class sums and their intersections with a subgroup. Coefficient restriction carries a full class sum to its intersection sum, so induced central functions have the expected class-sum formula.

External assumptions and dependencies

A finite group, subgroup H and the stated group algebra coefficient ring; evaluating an induced function uses the given local central character.

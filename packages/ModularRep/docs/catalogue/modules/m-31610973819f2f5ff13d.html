Purpose

This file combines the exact K₀ action from linear character tensoring with automorphism pullback.

Mathematical statement and assumptions

Compatible linear character parameterizations and field actions define semidirect representations on both exact Grothendieck groups, and the same decomposition map intertwines these actions.

Argument or construction

The natural isomorphism between field twist and linear character tensoring proves the semidirect action law on K-zero. The ordinary and modular compatible parameterizations then make decomposition equivariant for this action.

External assumptions and dependencies

The preceding decomposition/tensor hypotheses and compatible ordinary/modular linear character parameterizations of the same abstract group, with the explicit field action compatibility.

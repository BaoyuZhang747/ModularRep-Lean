Purpose

Defines the nonselective class of all certified lower algebraic pairs.

Mathematical statement and assumptions

FullHG contains every pair satisfying the fixed same-characteristic, simply-connected, simple-quotient and subdiagram semantics, including the ambient pair.

Argument or construction

Coverage presents every literal fixed-point group by a family. Classification supplies structural cases, with the prime-outside-order branch derived from the presented cardinality.

External assumptions and dependencies

Algebraic-group and Dynkin semantics remain explicit; callers cannot select an empty subclass.

Purpose

Transfers a complete witness for the same central-quotient raw pair using finite ordinary roots.

Mathematical statement and assumptions

The local character is always the given raw weight's own ordinary character.

Argument or construction

Canonical ambient/base/local equivalences identify both character restrictions. Target catalogues are transported from the existing witness and one-way butterfly/quotient principles carry all block equations.

External assumptions and dependencies

Existing pair witness, finite-root equalities and the one-way Butterfly and Martínez–Rizo–Rossi Lemma 3.14 sources.

Purpose

An ambient group equivalence and a compatible equivalence of normal subgroups transport a Brauer-character extension witness.

Mathematical statement and assumptions

A commuting group-equivalence square transports an existing irreducible Brauer extension witness to an extension of the correspondingly transported base character.

Argument or construction

Transport an extension witness along the commuting group isomorphism square. Evaluate restriction at a corresponding prime regular element to verify that the transported ambient character still restricts to the prescribed subgroup character.

External assumptions and dependencies

An existing actual character extension witness, the commuting group-equivalence/conjugation square and its coefficient/root transports. The file transports that witness rather than supplying a new extension theorem.

Mathematical statement and assumptions

Restrictions of one common finite multiplicative root correspondence agree on eigenvalues along any given group homomorphism whose two prime regular exponents divide the common root order.

Argument or construction

Restrict one common multiplicative root correspondence to the smaller finite root groups. Both evaluations of each eigenvalue then use the same ambient root image, proving compatibility along homomorphisms.

External assumptions and dependencies

One given multiplicative correspondence on a common finite root group and divisibility of both prime regular exponents into that root order.

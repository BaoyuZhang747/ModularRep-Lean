ModularRep.RegularRestriction

ModularRep/RegularRestriction.lean

theorem-developmentcurrent

Purpose

This file supplies the function level infrastructure needed before Brauer characters can be defined.

Mathematical statement and assumptions

Restriction to prime regular elements and homomorphism pullback are compatible with automorphism twists of functions and ordinary trace functions.

Argument or construction

Map prime regular elements along homomorphisms and pull functions back along that map. Applying this to trace proves the restriction/twist formula without interpreting modular trace as a Brauer character.

External assumptions and dependencies

The group homomorphism or automorphism and the prime regular element map; the trace specialization uses its actual representation.

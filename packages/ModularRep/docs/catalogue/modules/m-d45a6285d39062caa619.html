transport-adaptercurrent

Purpose

Späth's cyclic-outer argument first constructs the local character extension and then chooses a global extension in the block induced from that local extension.

Mathematical statement and assumptions

An extension choice dependent on the selected local extension and top block supplies the desired coherent top-level packet and its own local restriction.

Argument or construction

Make the choice of a global extension depend on the selected local extension and its top block. Restriction of that chosen coherent packet retains the supplied top-level compatibility; the target extension is not an independent arbitrary choice.

External assumptions and dependencies

The same matched raw weight and coherent extension packet, actual local quotient/ambient-base coordinates and compatible Brauer roots. Specified primitive-block identification and reduction support derive the base relation in the transport module; top extension choice is explicitly dependent on the selected local block.

Purpose

Constructs the actual quotient Brauer character representing the common trivial twist.

Mathematical statement and assumptions

The quotient uses the root convention of the same modular system and its trivial one-dimensional representation.

Argument or construction

The representation is irreducible and inflates through the actual quotient. Its values identify it with the existing lifted modular linear character, while the ordinary side keeps the selected quotient lift.

External assumptions and dependencies

Surjective pullback, root calibration and the established common-trivial-twist theorem.

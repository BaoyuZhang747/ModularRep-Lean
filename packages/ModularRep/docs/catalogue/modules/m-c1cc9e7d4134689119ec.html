Purpose

Supplies current higher-rank applications over finite splitting fields.

Mathematical statement and assumptions

The ordinary field splits the specified finite groups inside a complete modular system and need not be algebraically closed.

Argument or construction

The odd route retains the constituent, Conlon, extension and Hall proofs. The even route retains the guarded P38 and joint strong FLZ complete blocks and uses a finite-splitting family normalization source.

External assumptions and dependencies

Actual matrix/source/specified data and scoped finite-splitting published inputs, with the same cover and selected quotient tables.

Purpose

Stores Q=1 equality on the packet actually chosen.

Mathematical statement and assumptions

For every matched pair of the same correspondence, the constructor yields a named pair whose stored global and local extensions agree when its selected radical is trivial.

Argument or construction

It uses the common-extension construction in the bottom-radical branch and the general cyclic block construction otherwise. The conditional choice is made inside one packet, so normalization does not refer to a different existential witness.

External assumptions and dependencies

One actual matched pair in a fixed global correspondence, centreless selected-outer data, extension/root seed, Navarro9295/9495/820 principles, coefficient/catalogue data and defect-zero/trivial-weight normalization. The conditional choice retains Q=1 equality in the selected packet.

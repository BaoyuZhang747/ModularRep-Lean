Purpose

This is the covering-and-choice step in the cyclic proof of Späth (2013), Lemma 6.1.

Mathematical statement and assumptions

Given base induction, root-compatible extensions and the stated covering/twist sources, a global Brauer extension can be chosen in the uniquely selected induced ambient block.

Argument or construction

Use the interval central character identity to select the induced ambient block. Prove it covers the base block, then twist a given cyclic extension into that selected covering block while preserving restriction.

External assumptions and dependencies

Navarro 9.2/9.5 restriction-covering and 9.4/9.5 covering existence, the cyclic Brauer twist source from 8.20/8.7, actual finite roots and the Brauer tensor formula. Selection of the induced block uses the interval 4.14 central character identity.

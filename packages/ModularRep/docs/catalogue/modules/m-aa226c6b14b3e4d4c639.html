Package the three established full-witness presentations in one certificate type.

RawDefinition41Certificate records the retained witness. Definition41Certificate requires a compatible original or canonical witness on the same model.

Argument or construction

Construct the full certificate only from the required compatible witness. A forgetful passage to the raw certificate does not provide its converse.

The finite actual group, characteristic prime, compatible coefficient/root data, specified sets of primitive blocks and characters, and the imported transport results are fixed as in the declaration context. The same chosen matching, canonical availability and specified block compatibility are retained.

Purpose

Restricts a global correspondence to all central sectors.

Mathematical statement and assumptions

A global equivariant block-preserving equivalence with an explicitly supplied pair predicate gives the sector-family and legacy construction records with the same pointwise image.

Argument or construction

Block preservation implies sector preservation, so restriction gives each fibre map. The given pair predicate is reused in the legacy fields; this theorem does not manufacture a character-triple or extension assertion from an arbitrary predicate.

External assumptions and dependencies

The actual root and specified block operations, one global Brauer/weight equivalence with equivariance and block preservation, an explicitly specified pair predicate and a proof that it holds at every image. Sector and construction restriction preserve this predicate without proving an independent extension or character-triple assertion.

Purpose

Proves intermediate block equality for the same chosen Q=1 extension packet.

Mathematical statement and assumptions

For each intermediate subgroup, its global restricted character and catalogue determine the local character, local catalogue and self-induction equality.

Argument or construction

Identify the local intermediate subgroup with the global one. Transport the global character and central character catalogue along this equivalence. The selected blocks coincide and induction through the equivalent subgroup is self-induction; only coefficient field provenance is reused.

External assumptions and dependencies

ChosenGlobalExtensionData, QOneLocalTransportData and the global intermediate block data.

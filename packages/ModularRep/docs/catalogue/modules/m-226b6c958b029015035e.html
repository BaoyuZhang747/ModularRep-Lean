Purpose

Certifies rank 25 of the literal faithful matrix.

Mathematical statement and assumptions

The full 74 by 91 matrix has row-span dimension 25, also at the target root determined by the same prime regular embedding.

Argument or construction

Complete inverse/reconstruction checks give a representative certificate, and full-column expansion transfers it to the raw matrix. The same-iota specialization identifies the target root with the lift of the stored source root.

External assumptions and dependencies

The literal integer-polynomial checks and primitive 770385th root. The same-iota specialization uses SameIotaConductorRoot for the stated embedding; actual ordinary table values are not an input to this matrix theorem.

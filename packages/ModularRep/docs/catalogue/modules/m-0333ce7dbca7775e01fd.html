theorem-developmentcurrent

Purpose

This file connects the representation-level stable lattices to the exact Grothendieck groups of finite dimensional representations.

Mathematical statement and assumptions

Choosing a stable lattice yields a candidate exact K-zero reduction class for each ordinary representation. No independence of this choice is asserted in the file.

Argument or construction

Choose a stable lattice only to define its modular finite-representation object and exact K-zero class. This is a candidate reduction class, with lattice independence deferred to the character bridge.

External assumptions and dependencies

An existing modular system and the chosen stable lattice in each finite ordinary representation. Choice independence is deliberately absent from this candidate-class construction.

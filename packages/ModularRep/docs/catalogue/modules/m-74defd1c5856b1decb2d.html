Purpose

Shows that an invariant block has trivial central sector.

Mathematical statement and assumptions

If the centre has order three and the automorphism acts on it by inversion, a fixed primitive block has trivial central character.

Argument or construction

The sector is then equal to its inverse, so each value has square one. Its cube is also one because the centre has order three, forcing every value to be one.

External assumptions and dependencies

A literal primitive block fixed by an actual automorphism, centre cardinality three and inversion by that automorphism. Only the central character sector law is used, not local reduction or a quotient block catalogue.

Purpose

Fixes the same original principal constituent on a Spin-type component.

Mathematical statement and assumptions

The original local base, coefficient map and one-step return dictionary determine its standard finite Spin realization.

Argument or construction

A single Lang adjustment and both power equations place the original return in the standard full field image. The rank-three or higher-rank GGGR selector then fixes the transported character, which returns to the original local base.

External assumptions and dependencies

Original cycle and algebraic realization data, specified root/block support and the complete raw GGGR inputs.

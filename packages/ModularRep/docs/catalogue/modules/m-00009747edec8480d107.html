Purpose

Chooses a global extension together with root agreement.

Mathematical statement and assumptions

The prescribed base root and an ambient root seed give a cyclic Brauer extension whose ambient convention agrees with the retained base convention.

Argument or construction

The ambient embedding is reselected to match the base root on the relevant roots of unity. The cyclic extension principle is then applied, and the agreement is exported with the chosen extension.

External assumptions and dependencies

The selected centreless Brauer ambient and its base character, a root seed on that ambient, and the BrauerCyclicExtensionPrinciple. Root agreement with the prescribed base convention is derived before applying extension.

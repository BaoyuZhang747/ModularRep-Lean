Purpose

Exposes the packet's values on its own raw and transported representatives.

Mathematical statement and assumptions

Global extension values pull back to the selected Brauer character, and local extension values pull back to the raw weight's ordinary normalizer character.

Argument or construction

The proof expands extension, inflation and descent equations along the same embedding. Inner rebasing and representative transport give the corresponding formulas for a chosen conjugate raw representative.

External assumptions and dependencies

An already constructed SpathMatchedBlockCondition with its exact extension/inflation/descent fields. The representative variant additionally has an actual raw-weight twist equality; no independent value or normalizer-map compatibility is assumed.

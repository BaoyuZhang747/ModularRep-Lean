transport-adapterauxiliary

Purpose

Retains the table-row conjugator and transports base induction to the intersection presentation.

Mathematical statement and assumptions

Equality of global weight classes gives an explicit isomorphism-class conjugator and selected-radical conjugacy; a selected-idempotent match transports the existing base block induction.

Argument or construction

Extract a conjugator from equality in the orbit quotient and apply the subgroup projection to obtain the exact conjugate radical. For the base/intersection comparison, equality of the transported selected primitive idempotents implies equality of central characters. Rewrite the local character in the already supplied base induction relation.

External assumptions and dependencies

Global class equality and, independently, the selected intersection/base idempotent match and actual catalogues. Literal equality of the selected radical with the table radical is not asserted.

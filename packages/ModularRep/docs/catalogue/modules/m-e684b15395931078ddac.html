theorem-developmentcurrent

Purpose

This file computes the public interval-valued central Brauer map on one unnormalised global conjugacy class sum, then identifies its normalizer image with a local conjugacy class sum under a literal centralizer-intersection hypothesis.

Mathematical statement and assumptions

A specified equality between a normalizer class and the centralizer intersection of a global class makes the normalizer Brauer image of that global class sum equal to the nominated local class sum.

Argument or construction

Compare coefficients of the normalizer Brauer image of a global conjugacy class sum. The supplied class-intersection identity identifies it with exactly the nominated normalizer class sum.

External assumptions and dependencies

The specified global/normalizer class-intersection equality, actual centralizer and p-subgroup, and the constructed coefficient-level Brauer map.

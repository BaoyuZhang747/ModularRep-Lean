ModularRep.PrimeRegularClassFunction

ModularRep/PrimeRegularClassFunction.lean

carrier-constructioncurrent

Purpose

Brauer characters are class functions on the prime regular elements, but not every class function on that domain is a Brauer character.

Mathematical statement and assumptions

Prime regular class functions form the conjugacy-invariant function carrier with homomorphism pullback and automorphism twists; regular trace defines such a function.

Argument or construction

Bundle functions on prime regular elements that are constant on conjugacy classes. Pullback and automorphism twist preserve this property, and regular trace gives one such class function.

External assumptions and dependencies

A group, the prime regular element carrier and conjugacy-invariance proof of the function; regular trace specializes an actual finite representation.

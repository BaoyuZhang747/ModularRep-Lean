Purpose

Establishes the Q=1 intermediate block law on the actual ambient groups used by three branches.

Mathematical statement and assumptions

For centerless outer order two, a central extension with quotient order two, or the original group, every retained common Q=1 pair satisfies the intermediate block condition.

Argument or construction

The generic common-pair theorem reduces intermediate groups to the base or the whole ambient. Index at most two supplies this dichotomy in the first two branches; the original-group base is already top. The original block catalogue and an unselected top catalogue discharge the respective cases.

External assumptions and dependencies

The common-pair block theorem, actual carrier embeddings, outer-order or extension-order hypotheses, and a top block catalogue where required.

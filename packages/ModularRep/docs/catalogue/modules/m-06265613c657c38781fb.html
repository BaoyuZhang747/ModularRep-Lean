Purpose

Derives fixed counts for singleton specified fibres.

Mathematical statement and assumptions

A fixed block containing exactly one weight has exactly one fixed weight; a positive Brauer fixed count forces its block to be fixed.

Argument or construction

Equivariance closes the singleton weight fibre under the automorphism. On the Brauer side, a witnessed fixed character carries its block to itself.

External assumptions and dependencies

For the abstract theorem, an invariant singleton subset. The weight specialization uses the literal equivariant weight block map and a fixed block; the Brauer specialization uses its actual root/decomposition and a positive fixed-fibre cardinality.

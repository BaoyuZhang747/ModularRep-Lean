ModularRep.PaperProofs.TypeBPrincipalCommonTrivialTwist

theorem-developmentauxiliary

Purpose

Produces a common trivial modular and ordinary quotient twist at index two.

Mathematical statement and assumptions

For a modular linear character trivial on a normal subgroup with index two, its square is trivial; characteristic two forces the character itself trivial, giving a common trivial quotient twist.

Argument or construction

This forces it to be one, and the selected prime-to-two ordinary lift is also one. Tensoring the Brauer character and ordinary weight class by those same trivial characters gives the required common-twist identities.

External assumptions and dependencies

Actual index-two inclusion, selected root lift and the existing tensor character formulas.

Purpose

This module records the dependency audit of every named result in the manuscript's type B section.

Mathematical statement and assumptions

The dependency graph stores explicitly named external leaves and derived nodes with strictly decreasing ranks on edges.

Argument or construction

The rank decrease proves acyclicity and supports conditional evaluation of the graph. It does not instantiate the external representation theory or establish the current actual-group theorem.

External assumptions and dependencies

The seventeen named manuscript results and the rank-indexed induction step used in the high-rank proof are derived nodes. In particular, the high-rank proposition does not have a leaf asserting Assumption 5.3 at the current rank, that all blocks are BAW-good, or any form of the type B headline. Among those named results, B uses T,Q, L uses P,Q, and H uses P,T,Q,L.

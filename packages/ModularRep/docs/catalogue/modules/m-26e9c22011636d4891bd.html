Purpose

Computes the original odd-two target from one finite-root convention.

Mathematical statement and assumptions

The target root and every selected quotient root are fixed before the target problem is formed, and own normalizer reductions are computed by inflation.

Argument or construction

Navarro defect-zero reduction at the chosen quotient root supplies the local Brauer character. Coherence proves both root compatibility squares.

External assumptions and dependencies

Navarro 3.18 at actual quotient characters and the existing specified/group data; no matching or original witness is produced.

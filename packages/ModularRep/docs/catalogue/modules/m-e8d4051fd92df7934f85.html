Purpose

Defines the ambient carrier retaining the original character's stabilizer.

Mathematical statement and assumptions

The raw map has kernel exactly the character's central kernel, while the induced map from its own quotient is injective; the all-inner specialization takes that quotient as ambient group.

Argument or construction

The raw map is the quotient map followed by the stored base equivalence and inclusion. This derives the kernel formula and retains a possibly nontrivial central kernel rather than requiring raw injectivity.

External assumptions and dependencies

The OriginalSpathAmbient record specifies an actual finite ambient, normal base equivalent to the character's own quotient, original conjugation action, centre/centralizer and stabilizer-quotient laws. The identity specialization uses original-group perfectness, prime-to-p centre and all-inner action.

Purpose

Expands representative columns by scalars without losing an exact rank certificate.

Mathematical statement and assumptions

If each representative column reappears with scalar one, a row-inverse certificate on the representative columns gives the same rank after scalar expansion and zero-column insertion.

Argument or construction

Define expansion as a linear map. Linearity transports all row reconstruction equations, while the selected representative columns preserve the original pivot minor and inverse. The expanded certificate therefore has the same rank.

External assumptions and dependencies

The original row-inverse certificate and the scalar-one representative-column identities.

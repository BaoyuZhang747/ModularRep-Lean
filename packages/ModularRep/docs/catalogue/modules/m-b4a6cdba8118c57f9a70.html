ModularRep.PaperProofs.TypeBCentrelessCharacterQuotientEquiv

ModularRep/PaperProofs/TypeBCentrelessCharacterQuotientEquiv.lean

carrier-constructionauxiliary

Purpose

Each quotient uses the representation already selected by its own character. Centrelessness and a specified group equivalence determine the comparison.

Mathematical statement and assumptions

For a centreless original group, the central kernel attached to the prescribed reference character is the trivial subgroup.

Argument or construction

The quotient by that kernel is identified canonically with the original group. The construction records its projection values so later root, character, and weight transports use this precise equivalence.

External assumptions and dependencies

Calibration of the original root yields calibration on the other quotient.

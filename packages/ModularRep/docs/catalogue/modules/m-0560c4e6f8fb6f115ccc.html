Purpose

This file checks the logical case division at the end of the symplectic section.

Mathematical statement and assumptions

The displayed rank, finite-field and small-group prime-support assumptions place every admissible symplectic parameter tuple in one of the eight listed cases.

Argument or construction

Split rank two from higher rank, then parity and the small field/rank cases. The specified field description and small-group prime list exhaust the eight alternatives, without proving any branch's representation theoretic conclusion.

External assumptions and dependencies

The stated ranks and finite-field parity description plus the supplied small Sp6(2) prime-divisor alternative. No branch theorem is supplied by this case split.

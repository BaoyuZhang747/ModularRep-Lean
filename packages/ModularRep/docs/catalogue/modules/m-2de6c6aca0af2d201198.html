Purpose

Derives four-row fixed counts from the complete corrected Table 8 regardless of printed index.

Mathematical statement and assumptions

A complete radical catalogue bound to corrected Table 8 gives fixed radical classes and two fixed local rows for any four-element local catalogue.

Argument or construction

The literal table check shows every entry of total four has fixed count two. Find the representative of the given radical class by catalogue surjectivity. Transport total and fixed cardinalities along class equality and inner correction, then apply that table implication.

External assumptions and dependencies

Actual exhaustive radical catalogue, table permutation binding, actual local total/fixed counts and the chosen four-row bijection.

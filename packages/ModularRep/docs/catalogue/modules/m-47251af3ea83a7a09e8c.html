Purpose

This file formalises the case divisions at the ends of the type C, type B, and sporadic sections.

Mathematical statement and assumptions

The listed type-C, type-B and sporadic branch hypotheses imply the corresponding family goal by an exhaustive finite case division; branch conclusions themselves are supplied.

Argument or construction

Split the finite family parameter cases and apply the appropriate supplied branch implication. The sporadic constructor enumeration partitions the twenty-six names into twenty-two plus four; the branch conclusions remain assumptions.

External assumptions and dependencies

The finite node/case data and, for propagation, the supplied interpretation, external leaves, derived proof rules and semantic links. Ranked acyclicity does not inspect assumptions closed over by a proof rule.

Purpose

Malle--Testerman's rational-class parametrisation is applied separately inside each geometric class. The component group, inner automorphism element and rational-class fibre may therefore depend on that class.

Mathematical statement and assumptions

Every index of the same literal GGGR family has a geometric label and a rational class in that dependent fibre, with an exact function equality. Literal algebraic-group and source realization remains an explicit application obligation.

Argument or construction

The checked inner twisted-conjugacy deduction is reused fibre by fibre. Taylor's action is converted by the existing exact inverse-pullback identity before the resulting full-GGGR fixation is passed to the checked Proposition 4.9/Corollary 4.10 bridge. Indexed source handoff to the existing constructed-basis/projective formula proof.

External assumptions and dependencies

Literal algebraic-group and source realization remains an explicit application obligation. The dependent rational representative binds each literal GGGR index to one specified class; no equivalence of all classes with one component group is assumed. The same full GGGR family used by the Proposition 4.9 source is fixed, because each index is bound to its own geometric/rational class.

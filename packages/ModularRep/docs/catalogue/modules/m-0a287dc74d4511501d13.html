theorem-developmentcurrent

Purpose

Factor a conformal element into a multiplier-kernel element and a central scalar.

Mathematical statement and assumptions

A central scalar square realization of a surjective multiplier makes conjugation on its kernel inner, hence fixes every prime regular class function of that kernel.

Argument or construction

Factor a conformal element into a multiplier-kernel element and a central scalar. Its conjugation on the kernel is inner, so every prime regular class function is fixed.

External assumptions and dependencies

The multiplier homomorphism, central scalar map realizing its squares and surjectivity of squaring (or finite odd multiplier group). The function is a prime regular class function on the kernel.

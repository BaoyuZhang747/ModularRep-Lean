Purpose

Finds a sign-twisted extension in any covering block at index two.

Mathematical statement and assumptions

An actual irreducible extension and its literal restriction meet every specified covering block through either the original or quotient-sign twist, with an explicit characteristic-zero quotient character.

Argument or construction

Evaluate the supported trace of the selected block idempotent in the extension representation. Nonvanishing forces either the original or sign-twisted representation to select the block. The proved Brauer sign formula supplies the explicit twist relation.

External assumptions and dependencies

Actual affording/restriction identities, compatible roots, covering and complete block catalogues, in odd characteristic.

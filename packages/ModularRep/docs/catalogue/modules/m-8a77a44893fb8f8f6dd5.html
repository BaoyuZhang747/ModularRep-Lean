Purpose

Builds the selected integral projector independently of class choices.

Mathematical statement and assumptions

The complete class cover and inverse selected values define a group algebra element whose ordinary image is the character projector and whose residue has the required coefficients.

Argument or construction

A chosen class representative defines each coefficient, but the actual character's conjugacy invariance identifies its value independently of that choice. Mapping coefficients then gives both field formulas.

External assumptions and dependencies

A complete 108-class representative cover and actual inverse character values equal to the stored integer row. The coefficient maps from the fixed localization are constructed in the preceding module.

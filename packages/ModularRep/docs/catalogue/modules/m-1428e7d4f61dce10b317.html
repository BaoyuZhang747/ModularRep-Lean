Purpose

Identifies the full evaluated trivial-sector rows with representative-column expansion.

Mathematical statement and assumptions

The exact duplicate-column polynomial checks imply full-row evaluation is scalar-one expansion along columnLabel.

Argument or construction

Substitute the polynomial column identity before evaluation, preserving the tagged local root. The routing section shows each full value equals its pivot representative. These pointwise identities give equality with the linear expansion map.

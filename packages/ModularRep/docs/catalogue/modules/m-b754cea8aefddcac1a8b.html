Purpose

Proves the selected outer representative is non-inner.

Mathematical statement and assumptions

An actual ordinary character realizing the separated V3 values and the specified fusion between the last two classes detects a nontrivial outer class.

Argument or construction

Primitive-root relations show that the two selected values differ. An inner automorphism would preserve the ordinary class function, contradicting the supplied fusion and value equations.

External assumptions and dependencies

The finite V3 restriction-row binding over the primitive 29th-root encoding, an actual ordinary character realizing the selected row and the stated conjugacy fusion of the two separated classes. Non-innerness is concluded.

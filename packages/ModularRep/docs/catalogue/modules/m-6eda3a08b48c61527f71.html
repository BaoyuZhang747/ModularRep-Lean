Purpose

DecompositionBasicSetBridge deliberately permits an abstract modular label set.

Mathematical statement and assumptions

The integral basic-set bridge specializes to an actual literal IBr block with canonical twisting. The stated stability, decomposition and Conlon assumptions give an equivariant equivalence with its ordinary basic labels.

Argument or construction

Use actual IBr labels, canonical twisting and literal block support to specialize the restricted basic-set bridge. The stable reduction square and block stability supply the equivariant fibre map before the Conlon implication.

External assumptions and dependencies

An integral basic set on the actual IBr block, literal primitive decomposition, ordinary twist-compatible labels and automorphism stability. Its stable-reduction endpoint uses that compatibility source and the stated Conlon/Burnside hypotheses.

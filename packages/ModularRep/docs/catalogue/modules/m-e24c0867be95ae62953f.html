ModularRep.BrauerLocalExtensionInnerTransport

ModularRep/BrauerLocalExtensionInnerTransport.lean

transport-adaptercurrent

Purpose

An existing extension is transported along an actual commuting square of group equivalences.

Mathematical statement and assumptions

A specified inner conjugation carrying Q to R transports local normalizer and base characters and their extension witness to R, preserving the existing root-lift convention.

Argument or construction

Build normalizer and subgroup equivalences from a specified inner conjugation. Transport extension characters through the commuting square, retaining the finite root lift and the prescribed restricted character.

External assumptions and dependencies

An existing actual character extension witness, the commuting group-equivalence/conjugation square and its coefficient/root transports. The file transports that witness rather than supplying a new extension theorem.

Purpose

Forces a three-point involution fibre to be fixed using two invariant singleton subfibres.

Mathematical statement and assumptions

Two distinct fixed labels, each cutting out a singleton in an invariant three-element block fibre, imply three fixed elements.

Argument or construction

Equivariance keeps each singleton intersection invariant, so its unique element is fixed. Distinct labels give distinct elements. The involution parity theorem forces the remaining element to be fixed.

External assumptions and dependencies

Finite total three and the two singleton intersection counts, with equivariant block and radical labels.

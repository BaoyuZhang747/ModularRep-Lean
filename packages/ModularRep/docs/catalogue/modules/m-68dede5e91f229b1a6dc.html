Purpose

Retains guarded Jordan-label and named-principal-seed transport joins.

Mathematical statement and assumptions

A semisimple odd-order strict label is one, rank one passes to Type A, and a named principal seed transports to an actual equivalent carrier.

Argument or construction

Centralizer containment supplies quasi-isolation and the square relation kills the label. The seed uses the existing principal construction followed by fixed forward transport.

External assumptions and dependencies

Bonnafe's scoped source, Type A input and actual coefficient, block and carrier matching; no full-HG reduction is performed here.

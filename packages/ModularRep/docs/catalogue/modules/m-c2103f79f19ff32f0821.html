Purpose

For a positive defining exponent s, the r-th power of an endomorphism on its s-th-power fixed points has explicit inverse of exponent r * (s - 1).

Mathematical statement and assumptions

This construction requires neither global invertibility nor finiteness. Power values remain values of the same original endomorphism.

Argument or construction

This construction requires neither global invertibility nor finiteness. Its forward endomorphism is exactly the previously constructed fixedPowerEnd. A derived ambient-value equation identifies an actual return automorphism.

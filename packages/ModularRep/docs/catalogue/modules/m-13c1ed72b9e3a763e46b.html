Purpose

Computes specified block projection of every literal Spin PIM.

Mathematical statement and assumptions

For the existing specified Fourier projector and decomposition coefficients, proves principal PIMs project to themselves and unsupported PIMs project to zero.

Argument or construction

If a PIM label is unsupported, every selected ordinary coefficient vanishes and its projection is zero. Supported PIMs retain their block projection, so every projected PIM lies in the chosen projective space.

External assumptions and dependencies

Specified decomposition support and the established PIM scalar-product formula.

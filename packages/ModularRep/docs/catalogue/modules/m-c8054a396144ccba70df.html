Purpose

Derives the selected character norm from complete class data.

Mathematical statement and assumptions

The stated class centralizer orders, group order and forward/inverse selected values give norm one and a one-dimensional intertwining space.

Argument or construction

The sum of class sizes proves that the surjective class cover has no repetitions. The weighted value calculation yields the character norm, and the intertwining-dimension formula then makes every self-intertwiner scalar.

External assumptions and dependencies

The complete class cover, actual centralizer orders, group order and both forward and inverse values of the selected actual representation. Class distinctness, norm one and scalar self-intertwiners are derived, without a splitting-field source.

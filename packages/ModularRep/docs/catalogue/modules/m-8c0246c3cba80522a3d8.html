Purpose

Separates the all-intermediate block output from its construction.

Mathematical statement and assumptions

For each subgroup containing the base, actual global/local restricted characters, independent block-index types and complete catalogues satisfy the induction relation.

Argument or construction

The definitions state exactly the output data needed later. They impose neither a Q=1 hypothesis nor an equality between unrelated block-index carriers.

External assumptions and dependencies

This defines an output predicate for actual global/local class functions and a base/local subgroup pair. Witnesses consist of the specified irreducible restrictions and independent specified block catalogues with induction; no external existence principle is asserted.

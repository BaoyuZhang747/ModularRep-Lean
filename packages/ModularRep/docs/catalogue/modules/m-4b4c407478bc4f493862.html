Purpose

At the base intermediate subgroup, the global and local characters are canonical transports of the characters already contained in the Späth extension data.

Mathematical statement and assumptions

The positive-radical base packet records the required local-to-global base induction relation and has the stated own local character restriction at the base group.

Argument or construction

Package the selected positive-radical base induction requirement and identify the base local restriction of the actual extension packet. The base block equality is a hypothesis here, with its specified derivation provided by the transport module.

External assumptions and dependencies

The same matched raw weight and coherent extension packet, actual local quotient/ambient-base coordinates and compatible Brauer roots. Specified primitive-block identification and reduction support derive the base relation in the transport module; top extension choice is explicitly dependent on the selected local block.

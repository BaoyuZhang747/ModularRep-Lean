ModularRep.CharacterWeightRadicalProjection

ModularRep/CharacterWeightRadicalProjection.lean

transport-adaptercurrent

Purpose

A literal character weight contains a radical subgroup and a defect-zero local ordinary character.

Mathematical statement and assumptions

The radical-conjugacy class projection of actual character-weight conjugacy classes is well defined and equivariant for the canonical right automorphism action.

Argument or construction

Forget the local character of a raw weight and take the radical conjugacy class. Check invariance under both quotient relations and compatibility with the same right automorphism transport.

External assumptions and dependencies

The actual character-weight isomorphism/conjugacy relations and canonical right automorphism transport. No block source is required for this radical projection.

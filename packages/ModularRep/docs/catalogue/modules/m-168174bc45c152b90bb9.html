Purpose

Packages source-only data and actual targets for Type C branches.

Mathematical statement and assumptions

Lower-rank, defining, exceptional-cover and odd-two records remain valid; the higher odd/even wrappers carry the superseded incompatible coefficient conjunction.

Argument or construction

Each target computes a family, fixed cover and actual PSp coordinate before invoking its source theorem. The current finite-splitting module replaces only the two higher wrappers.

External assumptions and dependencies

Named branch sources, primitive coefficient and block data and exact covers; no complete witness is an input field.

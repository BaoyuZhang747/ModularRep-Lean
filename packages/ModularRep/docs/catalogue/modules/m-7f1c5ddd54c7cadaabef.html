Purpose

The structural input contains only the literal diagonal homomorphism, surjectivity and its exact Spin-join-centre kernel.

Mathematical statement and assumptions

The diagonal homomorphism is surjective with kernel equal to Spin joined with the special Clifford centre.

Argument or construction

Field preservation of this kernel induces an action on the quotient. Every automorphism of its two-element target is trivial, so the diagonal coordinate is field-fixed.

External assumptions and dependencies

The source's exact diagonal map is field invariant by quotient descent.

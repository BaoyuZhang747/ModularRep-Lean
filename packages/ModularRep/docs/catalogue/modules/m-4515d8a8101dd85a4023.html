Purpose

Compares weight-class inertias for principal objects covered by the same upper class.

Mathematical statement and assumptions

The result concerns the same covering fibre, not arbitrary character-weight pairs or raw inertia.

Argument or construction

Each covering fibre is one involution orbit, so stabilizer membership is constant on it. The equivariant seed identifies the character inertia, and products with the same subgroup or Hall preimage agree.

External assumptions and dependencies

Actual seed covariance and literal same-cover/covering hypotheses.

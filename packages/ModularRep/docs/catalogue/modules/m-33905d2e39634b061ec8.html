Purpose

Constructs the cyclic-extension input package on the selected named ambient.

Mathematical statement and assumptions

Unselected ambient and local block catalogues, interval data, a root seed and cyclic extension principle supply fixed local and initial global extensions and CyclicBlockSource once base induction is given.

Argument or construction

Construct the two extensions with their root agreement laws. Retain the local lift from the original selected reduction. Combine the actual quotient cyclicity, order bound and interval catalogue into the source record.

External assumptions and dependencies

BlockCatalogues, Spath coefficient field data, root seed and BrauerCyclicExtensionPrinciple; base block induction is a later argument.

Purpose

Derives the local extension by transporting the same global extension.

Mathematical statement and assumptions

For a normalized bottom-radical match, one global extension restricts to the required local base and gives literal equality of the ambient global/local characters.

Argument or construction

The original Q=1 equation is first descended to the own quotient. Transport through the existing local-group equivalence constructs the local extension, so no second independent choice remains.

External assumptions and dependencies

The same own-normalizer construction inputs, original ambient/local component and retained global extension, plus the normalized correspondence, raw-match equation and Q=1. No independent local extension is supplied.

theorem-developmentcurrent

Purpose

Restrict central coefficients to a subgroup, using conjugacy invariance to prove the result central.

Mathematical statement and assumptions

Coefficient restriction maps Z(kG) linearly into Z(kH). Composing it with a local central character defines an induced linear function, whose multiplicativity is not automatic.

Argument or construction

Restrict central coefficients to a subgroup, using conjugacy invariance to prove the result central. Compose with a local central character to obtain the induced linear function, without asserting multiplicativity.

External assumptions and dependencies

A group and subgroup H with the stated coefficient field; the induced function additionally uses a given local central algebra homomorphism. Its multiplicativity is not assumed.

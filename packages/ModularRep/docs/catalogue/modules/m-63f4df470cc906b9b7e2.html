Purpose

Builds the original family using the prime-centre dichotomy.

Mathematical statement and assumptions

For a universal prime-centre cover with outer order two and moved centre, the same normalized equivariant map plus unselected quotient/ambient data gives the complete original Definition 4.1 witness.

Argument or construction

The character's central kernel is either trivial or the full centre. The corresponding packet constructor handles each branch using the same match, roots and available extension/block principles.

External assumptions and dependencies

An ell-prime cover whose quotient map is universal, prime-order centre, quotient outer order two, and an automorphism with the stated two-coset decomposition and a moved central element. The actual root/carrier and canonical reductions, a normalized equivariant block-preserving map, defect-zero/trivial-weight sources, canonical compatibility, QuotientDataFamily, TrivialAmbientDataFamily, TrivialAmbientRootFamily, BrauerCyclicExtensionPrinciple, SpathCoefficientField and Navarro 9.2/9.5, 9.4/9.5 and 8.20 principles remain inputs.

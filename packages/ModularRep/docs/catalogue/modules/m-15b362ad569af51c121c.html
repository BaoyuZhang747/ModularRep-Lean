Purpose

Binds the finite principal Brauer table labels to the actual Omega(7,3) fibre.

Mathematical statement and assumptions

The same noninner SO element acts on both the complete table and the supported root-valued characters.

Argument or construction

Injectivity and complete support construct a label equivalence. Transport of fixed points gives twelve characters with eight fixed points for that involution.

Authenticated table, character, block and action dictionary, with explicit E3/U interpretation.

Purpose

Defines the original odd-field PSp target independently of any FM certificate.

Mathematical statement and assumptions

The target fixes the actual identity prime-to-two cover and requires an equivariant global map, central restrictions, extensions, all intermediate block inductions and both trivial-radical normalizations.

Argument or construction

Intrinsic-fibre constructions derive the radical partition and representative maps. Direct-Q and direct-H records retain the literal source subgroups rather than equating them with arbitrary selected representatives.

External assumptions and dependencies

Actual coefficient and specified block data; the definition does not supply an inhabitant or an opaque final predicate.

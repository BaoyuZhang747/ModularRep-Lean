Purpose

Diagnoses why an honest quotient representation cannot replace an associated obstruction class.

Mathematical statement and assumptions

If an extension of a base representation factors as an honest representation of G/N, then the base representation is trivial; a nontrivial base prevents such factorization.

Argument or construction

Every element of N maps to one in G/N, so the ambient representation acts trivially on N. Transport this through the extension's restriction equivalence to the selected base representation. A nonidentity base operator contradicts the resulting identity.

External assumptions and dependencies

Only the actual representation extension and proposed quotient factorization. This diagnostic does not claim the intended cohomology classes are nontrivial or incomparable.

Purpose

Realizes the same factor-one model at the original coefficient root.

Mathematical statement and assumptions

A top-base associated model with trivial factor set produces an irreducible extension whose character equals the retained original character.

Argument or construction

The factor-one operators define a genuine representation. Restricting along the top-subgroup equivalence identifies its character pointwise with the original one.

External assumptions and dependencies

The same top-base associated model with trivial factor set, irreducibility and its actual affording-character equation at the retained root. No fresh extension or catalogue source is input.

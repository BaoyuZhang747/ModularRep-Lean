Purpose

Routes every odd-field strict block to an actual Type A or principal symplectic carrier.

Mathematical statement and assumptions

A selected semisimple two-regular quasi-isolated label in the actual orthogonal dual is one, and the selected block contains the constant-one character.

Argument or construction

Bonnafe's guarded square implication and odd label order kill the label. Identity-series block interpretation then proves principality, with rank one routed to Type A.

External assumptions and dependencies

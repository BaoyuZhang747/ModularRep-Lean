Purpose

Converts a permuted row histogram into a fibre count.

Mathematical statement and assumptions

The cardinality of a value fibre of a finite row function equals its list multiplicity, including the four-row and singleton Boolean patterns.

Argument or construction

The proof rewrites the fibre cardinal as a list count and uses invariance under list permutation. This does not select an arbitrary distinguished actual row.

External assumptions and dependencies

A finite row function and a permutation equality with the stated value histogram. The special cases use the four-entry Boolean list or the one-entry list, with no actual-character realization.

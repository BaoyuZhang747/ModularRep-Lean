theorem-developmentcurrent

Purpose

This module packages the small certificate used by finite character-table calculations: selected rows have a nonzero square minor, and every row is an explicit linear combination of them.

Mathematical statement and assumptions

A finite row family with a nonzero nominated minor and explicit spanning coefficients has span dimension equal to the number of selected independent rows.

Argument or construction

A nonzero selected square minor proves independence of the selected rows. Supplied coefficients express every row in their span, so that span has exactly the nominated dimension.

External assumptions and dependencies

The nominated rows, a nonzero determinant of the selected minor and explicit coefficients spanning every row. Semantic association of numerical rows with character restrictions is external.

Purpose

Actual block actions on an affording representation, and Brauer values at elements killed by that representation.

Mathematical statement and assumptions

The actual primitive-block action is compatible with affording representations, and an element in the representation kernel has Brauer value equal to the degree.

Argument or construction

Use the identity operator on a kernel element to compute its characteristic polynomial. The Brauer-character definition then identifies the sum of lifted eigenvalues with the dimension.

External assumptions and dependencies

The actual affording representation, compatible root embedding and primitive-block action definitions. The kernel-value calculation follows from the identity operator on a kernel element.

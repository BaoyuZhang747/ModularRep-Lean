Purpose

This module contains the character-theoretic core of the cyclic outer action argument.

Mathematical statement and assumptions

For the actual IBr carrier and a cyclic field actor, the canonical semidirect stabilizer admits an extension of its selected base character under the supplied Brauer cyclic extension principle.

Argument or construction

Install the actual inner and outer actions on irreducible Brauer characters. Inner fixedness identifies the embedded base, and the stabilizer quotient calculation gives the actual extension over its semidirect stabilizer.

External assumptions and dependencies

The actual finite irreducible Brauer carrier with fixed roots, a cyclic outer automorphism group and BrauerCyclicExtensionPrinciple.

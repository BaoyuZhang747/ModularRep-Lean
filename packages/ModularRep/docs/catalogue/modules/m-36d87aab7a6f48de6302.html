Purpose

Checks faithful inverse rows 10 through 14.

Mathematical statement and assumptions

For these five basis rows, all 25 columns and six conductor tags satisfy the polynomial inverse identity, and the constants sum to the scaled Kronecker delta.

Argument or construction

Each row theorem reduces the explicit polynomial equality by decision. A separate constant-row theorem checks the sum of the six constants, so later evaluation can cancel the nonzero inverse denominator.

External assumptions and dependencies

The literal inverse polynomial data, quotient witnesses and constants for basis rows 10--14; all 25 columns and six tags are checked by decision. Specified ordinary-character realization is outside this file.

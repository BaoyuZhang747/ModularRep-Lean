Purpose

Proves full PSp automorphism equivariance of the descended FM map.

Mathematical statement and assumptions

Actual principal Brauer inflation and weight quotienting intertwine the canonical actions, so their composite with the same FM map is equivariant.

Argument or construction

The actual projective automorphism map is surjective by full-cover lifting. Injectivity of the correspondence then proves equality of matched class stabilizers.

External assumptions and dependencies

FM equivariance, actual quotient naturality, downstairs specified block support and full-cover lifting.

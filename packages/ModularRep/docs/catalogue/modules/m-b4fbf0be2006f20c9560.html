Purpose

Presents all Späth Definition 4.1 clauses for the original cover.

Mathematical statement and assumptions

An indexed witness retains the ell-prime cover, one equivariant block-preserving normalized correspondence, canonical compatibility and a packet for each radical-local fibre.

Argument or construction

Its methods extract the partition and local equivalences, full-centre lying-over, actual local block induction and the original automorphism stabilizer quotient. The Q=1 methods identify both the ordinary character and the stored common extension.

External assumptions and dependencies

The actual root, Brauer-character injectivity, literal carrier adapter, a canonical reduction for every raw weight, EllPrimeCoverSource, DefectZeroReductionSource and TrivialWeightSource index the target record. Its extracted conclusions require an existing Definition41Witness, whose fields contain the normalized map, canonical compatibility and actual packet at each representative fibre; the record is not asserted inhabited without those fields.

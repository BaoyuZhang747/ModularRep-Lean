ModularRep.OddQuasiIsolation

ModularRep/OddQuasiIsolation.lean

theorem-developmentcurrent

Purpose

This module isolates the elementary order argument used in the odd-field, characteristic-two reduction: an element whose order is coprime to 2 and whose square is one must itself be one.

Mathematical statement and assumptions

An odd semisimple label with the specified quasi-isolated order-four lift must be identity; together with the identity/principal source this excludes the given nonprincipal label from quasi-isolation.

Argument or construction

Project the supplied order-four lift to the semisimple label and combine its order bound with oddness. The label becomes the identity; the independent identity-label/principal-block rule then excludes a nonprincipal quasi-isolated label.

External assumptions and dependencies

The supplied Bonnafe order-four lift and identity-label/principal-block interfaces, label oddness and the actual projection/association data. This abstract exclusion argument does not prove a principal-series equality.

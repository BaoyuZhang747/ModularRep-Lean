Purpose

A named case model fixes the coefficient fields, specified group, prime-to-p cover and an equivalence from its simple quotient to the named base carrier; its conclusion is a fixed Definition 4.1 certificate.

Mathematical statement and assumptions

CaseConclusion requires the strengthened full Definition41Certificate. RawCaseConclusion is a separate weaker condition and is not the current Main target.

Argument or construction

Keep the same named group and prime, and distinguish the full and raw certificate types at the application boundary.

External assumptions and dependencies

A finite named base group and the explicit prime-dependent specified model. Its coefficient fields, root data, cover and quotient equivalence are fields to be supplied, while relevant primes are defined arithmetically.

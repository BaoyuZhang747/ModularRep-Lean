Purpose

The quotient action in this file is descended directly from the integral representation.

Mathematical statement and assumptions

The scalar-extension/quotient comparison intertwines the tensor action with the action descended directly from the integral representation, including stable lattice reduction modulo the maximal ideal.

Argument or construction

Descend the integral representation directly to the quotient lattice. Check the tensor/quotient comparison on pure tensors and quotient generators to prove it intertwines this natural action.

External assumptions and dependencies

The integral representation preserving the kernel ideal times the module and the tensor/quotient equivalence already constructed. The stable-lattice case uses the same residue-kernel data.

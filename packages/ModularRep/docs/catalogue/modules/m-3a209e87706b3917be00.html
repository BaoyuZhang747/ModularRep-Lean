ModularRep.LinearCharacterTensorAction

ModularRep/LinearCharacterTensorAction.lean

theorem-developmentcurrent

Purpose

The conformal-group arguments use an action obtained by tensoring an irreducible character with a linear character.

Mathematical statement and assumptions

Tensoring by an ordinary linear character preserves irreducibility and gives a character action compatible with field/automorphism pullback in the stated semidirect product.

Argument or construction

Scale representation operators by a linear character. The submodule lattice is unchanged, tensor multiplication and inverse give the character action, and automorphism pullback yields its semidirect compatibility.

External assumptions and dependencies

A unit-valued linear character and an actual ordinary irreducible realization; a compatible automorphism action is added for the semidirect specialization.

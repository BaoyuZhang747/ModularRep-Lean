Purpose

This module removes the monomial-naturality field from the E1 boundary of the component-return application.

Mathematical statement and assumptions

Rotation is an actual permutation of the finite cycle indices. The group-level successor and wrap equations imply the corresponding value equations, and finite-product reindexing determines the actual tuple of Brauer characters.

Argument or construction

The group-level successor and wrap equations imply the corresponding value equations, and finite-product reindexing determines the actual tuple of Brauer characters. The group-level normalised coordinate equations determine the full tuple of the twisted character by the actual finite rotation. The old component-return interface is produced from the strictly narrower source.

External assumptions and dependencies

The only character-theoretic input is ExternalProductData: prime, coherent roots, the external-product equivalence and its literal value formula (Navarro (8.21), pp. 176--177). The old component-return interface is produced from the strictly narrower source. Both coordinate and normalised permutation naturality are theorems, so neither remains an external input to this constructor.

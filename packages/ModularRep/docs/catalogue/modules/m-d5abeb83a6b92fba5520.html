Purpose

This file constructs the global and local group equivalences used to carry the block relation of a selected weight to the base intermediate subgroup.

Mathematical statement and assumptions

The original matched weight's block, transported through the canonical local quotient and two specified primitive-block identifications, gives the actual base induction relation for the coherent extension packet.

Argument or construction

Transport the original weight's selected block through the canonical quotient and embedded-local equivalences. Two explicit specified primitive-block matches and compatible Brauer reductions identify it with the base local block and derive the required induction relation.

External assumptions and dependencies

The same matched raw weight and coherent extension packet, actual local quotient/ambient-base coordinates and compatible Brauer roots. Specified primitive-block identification and reduction support derive the base relation in the transport module; top extension choice is explicitly dependent on the selected local block.

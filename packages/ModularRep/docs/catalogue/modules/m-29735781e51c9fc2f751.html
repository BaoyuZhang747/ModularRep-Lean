Purpose

The actual normalizer quotient for a central quotient.

Mathematical statement and assumptions

For a central subgroup in the quotient kernel, the normalizer quotient map has the expected restricted kernel and is an equivalence after quotienting when its surjectivity source holds.

Argument or construction

Compute the kernel by restriction and apply the quotient-isomorphism theorem. The argument does not require the central kernel to lie inside the radical subgroup.

External assumptions and dependencies

A central kernel subgroup, the actual normalizer map and the Navarro–Tiep normalizer-surjectivity input used by the statement. Containment of that kernel in the radical subgroup is not assumed.

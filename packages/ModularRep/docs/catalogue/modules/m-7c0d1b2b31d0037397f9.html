Purpose

This file supplies the coefficient-level calculation behind transitivity of block covering through an intersection.

Mathematical statement and assumptions

Actual central character covering equalities on a subgroup/intersection square, together with the two induction-definedness hypotheses, imply that the induced global central character covers the induced base central character.

Argument or construction

Express covering as equality of central character values on supported central elements. Coefficient restriction through subgroup intersections pastes the local equality with induced-character definedness to prove covering upstairs.

External assumptions and dependencies

Actual central character covering equalities and induction definedness on the displayed subgroup/intersection square. The file proves coefficient-level pasting, not a published existence theorem for covering blocks.

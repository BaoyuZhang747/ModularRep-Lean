Purpose

Corrects an outer automorphism to stabilize an actual radical representative.

Mathematical statement and assumptions

A fixed radical conjugacy class admits an inner correction stabilizing the subgroup, with unchanged actions on radical classes, weight classes and blocks.

Argument or construction

Extract a conjugating element from equality in the radical-class quotient and compose its conjugation with the original automorphism. Inner automorphisms are trivial on the three quotient-level carriers, so the correction preserves the actions needed for counting.

External assumptions and dependencies

Fixedness of the radical class and, for blocks, the inner-fixed law of the local block source.

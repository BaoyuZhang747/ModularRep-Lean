Purpose

The axis and a norm-one hyperbolic vector give an actual Spin element.

Mathematical statement and assumptions

The finite odd-field Spin projection is fixed and the rank supplies a hyperbolic coordinate.

Argument or construction

Multiply the axis vector by a norm-one hyperbolic vector to obtain a Spin element whose square is scalar minus one. Its matrix image is a nonidentity involution, so two divides the actual Omega order.

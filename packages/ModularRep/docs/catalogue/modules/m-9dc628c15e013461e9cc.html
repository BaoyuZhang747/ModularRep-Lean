Purpose

Named block fibres and literal support carry the same Brauer character. The conversion uses the named specified idempotent and no weight catalogue.

Mathematical statement and assumptions

The named Brauer fibre and the specified supported fibre are indexed by the same primitive idempotent.

Argument or construction

The fibre equivalence retains the underlying character literally. Block equivariance then shows that the full inertia of a supported character lies in the named block stabilizer.

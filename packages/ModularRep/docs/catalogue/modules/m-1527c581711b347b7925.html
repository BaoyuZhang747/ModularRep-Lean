Purpose

Literal block support places the full character stabilizer in the actual block stabilizer.

Mathematical statement and assumptions

The full inertia of a supported character is contained in a block stabilizer lying in the canonical inner range.

Argument or construction

The inner embedding is therefore surjective onto the required actor, with kernel the centre. Its quotient equivalence has the precise opposite-automorphism formula; with X as the whole base the only intermediate group is top.

External assumptions and dependencies

The original group and identity base embedding require no centreless or perfect-group hypothesis. This is the opposite action required by the literal criterion target.

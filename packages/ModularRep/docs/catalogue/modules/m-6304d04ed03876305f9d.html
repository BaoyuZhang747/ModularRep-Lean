Purpose

Fixes the full block-monomial normalizer of an independent product.

Mathematical statement and assumptions

The source quotient equivalence is tied to the actual normalizer matrix map, including permutations of equal basic blocks.

Argument or construction

The right-action convention uses column-block coefficients. The quotient square identifies actual lifts and prevents replacing the full normalizer by a mere product of basic quotients.

External assumptions and dependencies

An's normalizer theorem and explicit matrix coordinates; no character or radicality conclusion is included.

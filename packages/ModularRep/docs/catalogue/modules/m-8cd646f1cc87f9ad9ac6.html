Purpose

Derives Q=1 radical equality and common-extension block data from normalization.

Mathematical statement and assumptions

A weight equal to T.atOne d has selected radical and quotient radical bottom; cyclic extension and compatible roots/local characters yield one common extension and every intermediate block equality.

Argument or construction

An orbit equality with the trivial radical forces the selected subgroup itself to be trivial, since conjugation preserves bottom. Transport one cyclic extension to global and local carriers. At each intermediate subgroup the local normalizer is that subgroup itself, so transport the global catalogue and use self-induction.

External assumptions and dependencies

Normalized weight equality, cyclic extension principle, cyclic quotient, exact base-character fixedness, root and local Brauer compatibility, and global intermediate catalogues.

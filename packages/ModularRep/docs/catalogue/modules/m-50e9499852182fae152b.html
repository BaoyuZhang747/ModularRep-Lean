Purpose

Derives actual Frattini factorization from invariance of the same weight class.

Mathematical statement and assumptions

If every ambient conjugate of the embedded radical is base-conjugate, the base joined with its normalizer is the whole ambient group.

Argument or construction

Equality in both weight quotients provides an inner correction of the whole pair. The selected quotient map's equivariance supplies this class invariance for a matched witness.

External assumptions and dependencies

Existing actual matching and stabilizer action; no Frattini or subgroup equality source is introduced.

Purpose

The full Brauer automorphism stabilizer is a literal ambient group for a centreless group.

Mathematical statement and assumptions

For a centreless group the literal Brauer-character stabilizer is an actual automorphism ambient with an injective inner embedding and trivial base centralizer.

Argument or construction

Centrelessness makes inner conjugation injective. Compute the centralizer and centre directly, then identify the ambient quotient with the required stabilizer without choosing a split extension.

External assumptions and dependencies

The finite actual group, characteristic prime, compatible coefficient/root data, specified sets of primitive blocks and characters, and the imported transport results are fixed as in the declaration context. The same chosen matching, canonical availability and specified block compatibility are retained.

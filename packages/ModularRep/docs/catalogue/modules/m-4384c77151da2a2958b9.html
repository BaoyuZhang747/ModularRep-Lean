Purpose

Stores the polynomial quotients and constants witnessing faithful matrix identities.

Mathematical statement and assumptions

For each inverse entry and each reconstruction row, the file supplies literal quotient polynomials against the appropriate conductor modulus.

Argument or construction

The data distinguish inverse constants from modulus multiples. Evaluation modules consume the corresponding check propositions before concluding field identities.

External assumptions and dependencies

The literal data and closed identities described in this entry. Actual group, ordinary-character, block or coefficient identification is a separate binding and is not proved by this data module.

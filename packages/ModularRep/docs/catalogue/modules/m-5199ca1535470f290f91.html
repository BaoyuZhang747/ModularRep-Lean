Purpose

Promotes selected-outer equivariance to full automorphism equivariance.

Mathematical statement and assumptions

A map intertwining the selected outer involution is fully Aut-equivariant if the C2 outer-class kernel fixes both carriers and the selected class is nontrivial.

Argument or construction

An automorphism in the kernel acts trivially on each side. Every other automorphism differs from the selected outer element by a kernel element because Sym(Fin 2) has one nonidentity element. Apply the two action laws and selected intertwining. The combined endpoint retains both known fibre maps and block preservation.

External assumptions and dependencies

The actual outer-class homomorphism, selected nontriviality and kernel action laws, plus the existing outer-equivariant three-block construction.

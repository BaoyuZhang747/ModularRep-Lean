Purpose

Constructs chosen global extension data with a compatible reselected ambient root.

Mathematical statement and assumptions

A selected centerless Spath ambient, cyclic extension principle and any seed ambient root give ChosenGlobalExtensionData.

Argument or construction

Identify the base character transported through the central quotient with the original character on the embedded group. Extend the base root convention to a reselected ambient root agreeing on all relevant roots of unity. Apply the bare cyclic character-extension theorem and package that precise root and witness.

External assumptions and dependencies

Centerlessness, the full selected semidirect automorphism presentation, cyclic Brauer extension principle and an ambient root seed. No relation with the fixed local block is supplied.

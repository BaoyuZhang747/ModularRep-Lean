carrier-constructioncurrent

Purpose

This file does not define Brauer characters, blocks, weights, induced blocks, or modular character triples.

Mathematical statement and assumptions

Context defines abstract block/radical/sector and compatibility predicates; Candidate stores the equivariant block matching and derived partition, while Certification/Data adds intermediate blocks, extensions, triples and Q=1 normalization.

Argument or construction

Package the actual application predicates separately from the equivariant block-preserving matching. Derive radical partitions and local fibre maps from the candidate; additional certification yields exact Q=1 normalization and the extension, block and triple clauses.

External assumptions and dependencies

An abstract Context with typed block, radical and sector maps plus the named compatibility predicates. Candidate and Certification/Data require their displayed laws; these are not concrete character constructions.

Purpose

Three distinct specified block roles exhaust an actual block catalogue of cardinality three.

Mathematical statement and assumptions

Three distinct specified block roles exhaust an actual block catalogue of cardinality three.

Argument or construction

The role map is injective; equality of finite cardinalities makes it surjective. Package the resulting bijection as the role-to-block equivalence without using character values.

External assumptions and dependencies

A finite actual block catalogue, cardinality three, and three pairwise distinct designated block roles. No character-value or decomposition-number calculation enters the cardinality argument.

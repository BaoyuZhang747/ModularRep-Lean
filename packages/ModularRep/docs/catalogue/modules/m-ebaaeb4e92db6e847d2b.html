theorem-developmentcurrent

Purpose

This file proves the separation result needed to identify simple group algebra module classes with the function-valued set IBr.

Mathematical statement and assumptions

With the fixed finite roots and stated splitting fields, equality of irreducible Brauer functions implies isomorphism of the affording simple modules, giving the simple-class/IBr equivalence.

Argument or construction

Reflect equality of lifted root sums to equality of modular traces, extend from regular elements using the primary decomposition, and apply simple trace separation. This proves injectivity and the simple-class/IBr equivalence.

External assumptions and dependencies

Finite G, algebraically closed characteristic-p k, characteristic-zero K and the explicit finite root correspondence. Trace recovery and simple modular trace separation are earlier internal results.

Purpose

This file gives the literal function equality saying that an irreducible Brauer character of N_G(Q) is the reduction of the ordinary inflation of a character of N_G(Q) / Q.

Mathematical statement and assumptions

Ordinary Brauer reduction is the predicate that the ordinary irreducible function restricted to prime regular elements equals the specified irreducible Brauer function under the given root convention.

Argument or construction

Define ordinary Brauer reduction as equality between restricted ordinary values and the specified irreducible Brauer function. This is a compatibility predicate; it does not assert reduction exists or is irreducible.

External assumptions and dependencies

Actual ordinary and irreducible Brauer functions with the specified prime regular root embedding; equality of restricted ordinary values with the Brauer values is the predicate being defined.

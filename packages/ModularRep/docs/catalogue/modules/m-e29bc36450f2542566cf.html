Purpose

Defines the complete fixed-block extension data for a prescribed raw weight.

Mathematical statement and assumptions

Its local group is the normalizer of the radical image under the displayed base equivalence.

Argument or construction

The record specifies global and local extensions, their restriction values and all intermediate block equations as output data. It makes the actual embeddings explicit rather than hiding them in a block-goodness predicate.

External assumptions and dependencies

The chosen specified block, root-valued Brauer character, own raw weight and actual base equivalence.

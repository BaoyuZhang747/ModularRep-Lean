Purpose

Identifies descended and canonical normalizer roots.

Mathematical statement and assumptions

The root table obtained by surjective descent agrees with the quotient ambient's canonical normalizer convention, preserving the same local Brauer values and reduction.

Argument or construction

Both roots restrict the original ambient convention. Rewriting their equality transports the already constructed normalizer character without adding a root-agreement premise.

External assumptions and dependencies

The same own-normalizer descent inputs and canonical ambient root embedding. Agreement of the descended normalizer root with the quotient ambient's canonical root is proved; no additional root-matching premise is needed.

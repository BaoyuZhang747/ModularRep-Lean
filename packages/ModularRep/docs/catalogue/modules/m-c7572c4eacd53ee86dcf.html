Purpose

Derive noninnerness of a selected automorphism from its action on an actual Brauer character.

Mathematical statement and assumptions

A group whose outer automorphism quotient has order two obtains the required C2 action when a selected automorphism moves an actual Brauer character.

Argument or construction

Inner automorphisms fix Brauer characters, so the selected automorphism is noninner. Combine this fact with the quotient-cardinality source and the existing quotient construction to obtain the operational outer action.

External assumptions and dependencies

The finite actual group, characteristic prime, compatible coefficient/root data, specified sets of primitive blocks and characters, and the imported transport results are fixed as in the declaration context. Outer-quotient cardinality, kernel/class-map laws or the stated specified Brauer census are input facts; the named sporadic identification is not derived here.

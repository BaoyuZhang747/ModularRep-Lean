carrier-constructionauxiliary

Purpose

Combines all trivial-sector weights from a downstairs radical catalogue.

Mathematical statement and assumptions

The sigma of downstairs local row carriers is equivalent to the actual original trivial-sector set of weights, giving its cardinality as a finite sum.

Argument or construction

Lift radical representatives using the radical-class equivalence and prove their class map bijective. Partition sector weights by radical class, then use local descent at each lifted representative and compose the equivalences.

External assumptions and dependencies

Complete downstairs radical catalogue, canonical local reductions, quotient and primitive-image compatibility.

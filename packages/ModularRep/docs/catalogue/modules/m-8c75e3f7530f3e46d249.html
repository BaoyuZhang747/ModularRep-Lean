Purpose

Constructs global and local extensions for the same principal raw pair.

Mathematical statement and assumptions

The local ambient is the normalizer of that weight's radical image in the actual Brauer inertia.

Argument or construction

Class invariance fixes the transported local character. The quotient bound implies cyclicity, and the extension principle supplies both irreducibles using one compatible ambient root seed.

External assumptions and dependencies

Actual class invariance, cardinal bound at most two, cyclic extension and finite-root agreement.

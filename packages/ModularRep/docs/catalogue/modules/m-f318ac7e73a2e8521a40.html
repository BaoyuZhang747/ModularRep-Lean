Purpose

This module contains only the representation-level passage from a quotient local extension to the literal pair stabiliser.

Mathematical statement and assumptions

An extension on the constructed local quotient inflates to an actual representation extension on the original local group, compatible with the selected reduction.

Argument or construction

Pull back a local representation extension along the quotient map. The quotient restriction square shows that its inflated representation extends the selected original local representation.

External assumptions and dependencies

An already established local representation extension on the quotient, the selected local reduction source and the exact inflation/restriction square.

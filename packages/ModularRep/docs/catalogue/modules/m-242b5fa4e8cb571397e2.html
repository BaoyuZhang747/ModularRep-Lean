Purpose

Excludes weights on the order-three radical class.

Mathematical statement and assumptions

Complete degree coverage of the actual normalizer quotient with the listed quotient order implies that it has no local defect-zero character.

Argument or construction

No listed degree has the full quotient 3-part, so every covered irreducible fails defect zero. The actual local-character/weight-radical-fibre equivalence then excludes that radical conjugacy class from every weight.

External assumptions and dependencies

The actual normalizer-quotient order and degree coverage of all its ordinary irreducibles by the displayed list. No distinct enumeration, splitting-field source or preassigned defect-zero emptiness is required.

Purpose

Stores the 25-column faithful arithmetic presentation.

Mathematical statement and assumptions

Seventy-four integer-polynomial rows, a 25-row basis, scaled inverse entries and reconstruction coefficients define residuals grouped by six conductors.

Argument or construction

The inverse residual is a finite conductor-tagged dot product. The reconstruction residual subtracts the prescribed basis combination from twice each row, preparing identities checked in separate modules.

External assumptions and dependencies

The literal data and closed identities described in this entry. Actual group, ordinary-character, block or coefficient identification is a separate binding and is not proved by this data module.

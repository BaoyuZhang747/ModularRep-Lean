Purpose

The one raw E1 coefficient/intersection field is used locally to choose a global class for each nonzero local class coefficient.

Mathematical statement and assumptions

The raw Navarro class-intersection source at every relevant nonzero local coefficient constructs an actual preimage of the local block idempotent under the normalizer Brauer map.

Argument or construction

For each nonzero coefficient of a local block idempotent, select a global class with the supplied intersection property. Sum its class sums with those coefficients to construct a preimage under the normalizer Brauer map.

External assumptions and dependencies

The exact nonzero-class-coefficient/global-class-intersection direction of Navarro Theorem 4.15 and Lemma 4.16. The actual p-subgroup and local defect predicate are fixed before constructing the preimage.

Purpose

Turns an exact central character table binding into block induction to a specified target.

Mathematical statement and assumptions

Equality of the actual local block's interval-composed central character map with a separately specified target block's map yields induction to that target.

Argument or construction

Navarro 4.14 gives definedness and identifies the induced central character function with the interval composition. Substitute the supplied linear-map equality to obtain the target block law.

External assumptions and dependencies

The actual normalizer interval, Phase A Navarro 4.14 source and exact central character equality. Target identification, weight coverage and iBAW data are not consequences of the transcript alone.

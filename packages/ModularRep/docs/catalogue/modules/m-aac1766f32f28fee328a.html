Purpose

Computes actual raw-weight inertia and common conjugate character inertias for principal matches.

Mathematical statement and assumptions

Every representative of a covered class is included, with the original SO correspondence fixed.

Argument or construction

Matched class inertia and the raw/class inertia product give the character inertia as embedded Omega times raw normalizer inertia. Index two gives the commutator bound and invariance under all SO conjugates.

External assumptions and dependencies

Actual ambient field matching, raw inertia geometry and the original occurrence/covering anchors.

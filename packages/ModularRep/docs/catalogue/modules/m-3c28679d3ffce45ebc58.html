Purpose

Retains the common Q=1 extension for every selected global model on each actual ambient branch.

Mathematical statement and assumptions

SameMapQOneOutput, canonical reductions and block compatibility imply EveryModelCommon for the centerless and central-two ambients and its fixed-root version for the original group.

Argument or construction

The same-map normalization identifies the actual canonical local Brauer character with the global character. The generic every-model construction then uses the literal Q=1 normalizer/base equivalences. Root seeds supply the two larger ambients, whereas the original branch transports the already fixed root embedding.

External assumptions and dependencies

Defect-zero reduction and trivial-weight sources, canonical local availability and compatibility, SameMapQOneOutput, and larger-ambient root seeds.

Purpose

Binds the checked trivial-sector matrix to actual total and fixed Brauer counts.

Mathematical statement and assumptions

Actual ordinary decomposition, complete 108-row trivial-sector data, 91 regular-class representatives and literal values give total 41; the actual outer fusion gives fixed count 31.

Argument or construction

The same-iota rank certificate computes the actual sector dimension. Under the fusion binding, the symmetrized rank 36 computes the plus-space dimension. The involution formula yields 2·36−41=31, then the fixed-carrier equivalence identifies the actual fixed subtype.

External assumptions and dependencies

Specified character values, complete ordinary and class catalogues, the original conductor root and actual automorphism fusion/decomposition.

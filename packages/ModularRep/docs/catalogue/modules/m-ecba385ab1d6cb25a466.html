Purpose

The target ambient acts by its actual field action followed by SO conjugation.

Mathematical statement and assumptions

The same Spin-to-Omega equivalence intertwines this action with the existing action of the Clifford ambient modulo the Spin centre. Residual scalars fix Omega and centralize its actual embedded image; they are not asserted to be the centre of the entire ambient group.

Argument or construction

Equality of the actual homomorphisms into the automorphism carrier. It is an intertwining statement, not a full-automorphism surjectivity claim.

External assumptions and dependencies

Uses the preceding constructions in ModularRep.PaperProofs.TypeBCliffordOrthogonalFullFieldBinding, ModularRep.PaperProofs.TypeBCliffordOrthogonalResidualQuotient.

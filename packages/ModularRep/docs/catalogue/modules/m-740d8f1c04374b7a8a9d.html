Purpose

Derives base block induction and the radical interval for an exceptional principal pair.

Mathematical statement and assumptions

The supported Brauer character and its matched raw weight lie in the same literal principal block.

Argument or construction

The canonical local reduction computes the weight's own character block, giving the base induction equation. The embedded radical supplies the central Brauer interval required for later covering.

External assumptions and dependencies

Specified principal support, guarded local reduction/block identity and the actual embedded normalizer.

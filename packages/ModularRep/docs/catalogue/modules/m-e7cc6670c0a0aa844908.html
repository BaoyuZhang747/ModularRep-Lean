ModularRep.IrreducibleBrauerCharacter

ModularRep/IrreducibleBrauerCharacter.lean

carrier-constructioncurrent

Purpose

An element of IBr is a prime regular class function together with a witness that it is afforded by an irreducible finite dimensional modular representation.

Mathematical statement and assumptions

IBr consists of functions afforded by irreducible finite modular representations under the given root embedding, and representation twisting realizes its automorphism action.

Argument or construction

Define irreducible Brauer functions by existence of an irreducible finite representation under the specified root embedding. Twisting an affording representation realizes the pulled-back function and establishes the carrier action.

External assumptions and dependencies

The fixed finite root correspondence and a finite-dimensional irreducible affording modular representation. Carrier action uses automorphism twists of that realization.

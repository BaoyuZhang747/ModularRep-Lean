ModularRep/LinearCharacterOrthogonality.lean

theorem-developmentcurrent

Purpose

This file proves the elementary translation formula for the sum of the values of a linear character of a finite group.

Mathematical statement and assumptions

Distinct linear characters of a finite invertible-order subgroup have zero cross weighted-sum product, so the normalized central character idempotents are pairwise orthogonal.

Argument or construction

Translate a nontrivial linear character sum by an element where its value differs from one. The sum must vanish, and multiplication of weighted group algebra sums then proves orthogonality of distinct character idempotents.

External assumptions and dependencies

A finite subgroup, its unit-valued linear characters and invertible subgroup order for normalized idempotents. No Brauer character source is required for the finite character-sum orthogonality.

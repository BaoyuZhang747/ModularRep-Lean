Purpose

This file provides the low-level bridge from a complete decomposition by primitive central idempotents to literal elements of the group algebra centre.

Mathematical statement and assumptions

Every idempotent in the supplied primitive block family is canonically an element of the group algebra centre, with its original algebra element as coercion.

Argument or construction

Package the centrality proof of each supplied block idempotent into an element of the group algebra centre. The coercion back to the algebra is the original idempotent.

External assumptions and dependencies

The centrality field of the supplied primitive block decomposition.

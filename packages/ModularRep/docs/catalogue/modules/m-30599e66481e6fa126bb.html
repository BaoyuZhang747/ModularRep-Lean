Purpose

This module contains the group-theoretic identifications between the restricted stabiliser of a selected character weight, its embedded copy in the full pair stabiliser, and the normaliser of the selected radical subgroup.

Mathematical statement and assumptions

The selected radical embeds normally in the actual pair stabilizer, and the induced local quotient-image map agrees with the canonical original normalizer quotient.

Argument or construction

Embed the selected radical normally in the actual pair stabilizer. The quotient-image map agrees elementwise with the original normalizer quotient under the canonical embedded equivalence.

External assumptions and dependencies

The actual canonical semidirect pair stabilizer, selected raw weight and RawNormalizerQuotientInput identifying the embedded radical/local quotient.

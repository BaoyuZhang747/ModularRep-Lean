ModularRep.IBrSimpleModuleClass

ModularRep/IBrSimpleModuleClass.lean

theorem-developmentcurrent

Purpose

The Brauer character of a simple k[G]-module defines an element of the function-valued set IBr.

Mathematical statement and assumptions

The actual IBr carrier of a finite group is finite because finite simple-module classes surject onto it. Every predicate fibre of IBr is consequently finite.

Argument or construction

Map finite simple-module classes onto the function-valued irreducible Brauer carrier. Surjectivity gives finiteness even before injectivity is used, and every predicate fibre is a finite subtype.

External assumptions and dependencies

Finite G and its finite simple-module class set, with a fixed root embedding defining IBr. Finiteness uses surjectivity alone, not character injectivity.

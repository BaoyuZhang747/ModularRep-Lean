Purpose

Moves table block induction to the normalizer of the actual selected weight representative.

Mathematical statement and assumptions

The retained conjugator, table central character binding and uniform local-operation naturality give induction for the selected representative's attached block.

Argument or construction

Construct the normalizer equivalence and its commuting ambient conjugation square. Inner conjugation fixes the ambient block central character. Equality of weight isomorphism classes identifies the selected ordinary character with the canonical twist, so naturality proves the selected-idempotent and central character matches needed to transport induction.

External assumptions and dependencies

The row alignment, Navarro 4.14/table binding and uniform RightTwistNaturality for the local block operations. No second induction hypothesis or literal radical equality is introduced.

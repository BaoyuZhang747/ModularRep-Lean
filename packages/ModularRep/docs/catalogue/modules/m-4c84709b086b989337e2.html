Purpose

Specify the actual block, rank, defect and weight-count input for the Baby Monster application at two.

Mathematical statement and assumptions

The Baby Monster two-prime source interface fixes two distinct specified block roles, the principal ordinary row, canonical Brauer ranks, the other defect order eight and total weight counts.

Argument or construction

Package the specified selectors, splitting data and finite decomposition information that the numerical proof consumes. These fields are input obligations rather than table or group facts proved by the interface.

External assumptions and dependencies

The finite actual group, characteristic prime, compatible coefficient/root data, specified sets of primitive blocks and characters, and the imported transport results are fixed as in the declaration context. The raw input constructor retains the actual full-cover, named-base equivalence, prime, source theorem, numerical and representation hypotheses of its application; no inhabitant is manufactured for this telescope.

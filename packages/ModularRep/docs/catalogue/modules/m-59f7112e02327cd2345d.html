Purpose

Proves the class-function consequence of an inner relative-quotient action.

Mathematical statement and assumptions

If the induced automorphism of the actual inertia quotient is inner, every quotient class function is fixed.

Argument or construction

The quotient is formed as a genuine group. Conjugacy invariance identifies evaluation before and after the action.

External assumptions and dependencies

The innerness identification for the quotient action.

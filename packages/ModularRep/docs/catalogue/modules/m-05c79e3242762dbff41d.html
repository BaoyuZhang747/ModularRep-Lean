Purpose

Derives local interval evaluations from bound local defects.

Mathematical statement and assumptions

For the same specified operations and an order-nine radical, local block defect-order data and the uniform upper defect witness imply interval evaluation one at role one.

Argument or construction

The local cardinal bound identifies its defect with the normal radical. The induced block has exact order-nine defect and hence is role one, so its catalogue character evaluates its own idempotent to one.

External assumptions and dependencies

The same actual operations and three-role ordinary allocation, role-two trivial defect, an order-nine radical, local defect-order and existence data, the uniform First Main upper witness and the stated local row block defect.

Purpose

Exports the V3 raw and symmetrized rank certificates to the actual nonprincipal census and Q=1 window.

Mathematical statement and assumptions

The canonical V3 binding gives raw rank four and symmetrized rank three; actual coordinate binding gives Brauer signature (4,2) and feeds the same ranks through the normalized correspondence with concrete Q=1 matched blocks.

Argument or construction

Build the replay source from the sixteen selected entries and row relations. Transport both ranks through injective evaluation and apply the involution trace formula. The last wrapper passes precisely these derived data to the existing concrete Q=1 endpoint.

External assumptions and dependencies

Canonical supplement/V3 binding, primitive root encoding, actual restriction-space coordinate binding and all independent local, action, defect-zero, An–Dietrich and cyclic-extension sources of that endpoint.

Purpose

Derives surjectivity of the already specified Jordan packet map from base Morita equivalence.

Mathematical statement and assumptions

A base Morita equivalence and uniform calibration of tensor characters with the fixed Jordan map imply that map is onto the original ambient packet.

Argument or construction

Essential surjectivity supplies a supported preimage representation for each ambient simple. Simplicity transport and uniform character calibration identify its tensor character with the stored Jordan image.

External assumptions and dependencies

Supported-simple dictionary, specified base Morita equivalence, support and same-Jordan calibration.

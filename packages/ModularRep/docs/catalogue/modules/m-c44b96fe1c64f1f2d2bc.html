transport-adapterauxiliary

Purpose

Gives actual Brauer fibre and fixed-count transport for every trivial-sector block.

Mathematical statement and assumptions

Each specified trivial-sector primitive block has a Brauer fibre equivalent to that of its computed quotient index, with equal fixed cardinalities under intertwined automorphisms.

Argument or construction

Restrict canonical inflation/descent using the specified block-image law and flatten the sector/block subtype. The inverse is literal inflation. The automorphism square identifies fixedness, so restricting the same equivalence proves the fixed-count equality.

External assumptions and dependencies

Actual block decompositions, central p-prime quotient and primitive-image source; no chosen reference character or block inhabitant is required.

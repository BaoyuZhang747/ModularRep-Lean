Purpose

Builds the specified matrix and basis data from the selected ordinary rows.

Mathematical statement and assumptions

Given actual selected ordinary rows, geometric fibre data, projectivity and the class count, constructs the specified matrix source and basis source indexed by the same exhaustive rational classes.

Argument or construction

Classwise diagonal models are transported through the enumeration and an injective geometric code, including empty fibres. Principal support, projectivity, nonnegativity and the dimension count populate the basis source.

External assumptions and dependencies

Selected abelian/nonabelian families, Taylor's support-to-closure direction (Lemma 14.15/Proposition 15.2), the Chaneb/CE rational-class count, principal-series certificate and specified induction/PIM inputs.

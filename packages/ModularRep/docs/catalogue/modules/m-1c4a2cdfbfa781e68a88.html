Purpose

Any original block-preserving equivalence has the required literal Q=1 normalization, by defect-zero block uniqueness and the canonically derived at-one block relation.

Mathematical statement and assumptions

Any block-preserving map into the canonical set of weights is already normalized on a defect-zero singleton block.

Argument or construction

The unique weight in that block is its trivial-radical weight. Since the map preserves the block, its value must equal that weight, so no replacement of the map is required.

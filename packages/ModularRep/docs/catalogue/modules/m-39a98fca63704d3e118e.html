Purpose

Produces Q=1 intermediate block data by self-transport.

Mathematical statement and assumptions

A common global extension and its restriction to an intermediate subgroup give the local character and induction relation using the same specified catalogue.

Argument or construction

The local group is equivalent to the whole ambient by its actual subtype map. Transporting the intermediate restriction through the corresponding intersection equivalence proves the block relation.

External assumptions and dependencies

The stored local-group equivalence whose underlying map is inclusion, one global extension character and its actual intermediate irreducible restriction, a complete global block catalogue and the coefficient field record. The local catalogue is transported from that one catalogue.

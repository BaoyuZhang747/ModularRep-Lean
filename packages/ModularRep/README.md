# ModularRep

Lean constructions in ordinary and modular representation theory of finite
groups. Use the module named in the library manual for each result.
`ModularRep.Library` imports a selection of general constructions.

The [application package](../../README.md) and its
[formalisation report](../../output/pdf/formalisation-report.pdf) accompany this
library. The [library manual](../../output/pdf/library-manual.pdf) is the sole
maintained manual. The repository README and STATUS.json state the verification
scope and external assumptions. The pinned Lake files specify the dependencies.
